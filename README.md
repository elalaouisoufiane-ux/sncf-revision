# SNCF Traction Academy

Application statique de révision personnelle en HTML, CSS et JavaScript.

## Ouvrir le site

Ouvre `index.html` dans un navigateur. Les données sont sauvegardées dans le LocalStorage du navigateur.

## Ajouter du contenu

- `data/definitions.js`: définitions, catégories, difficultés et tags.
- `data/abbreviations.js`: abréviations importées depuis `Abreviation2.html`.
- `data/vocabulary.js`: vocabulaire importé depuis `preview.html`.
- `data/courses.js`: chapitres, sous-chapitres et blocs de cours.
- `data/summaries.js`: résumés liés aux cours par `courseId`.
- `data/quiz.js`: flashcards et questions.
- `data/planning.js`: événements initiaux optionnels.

Garde les `id` stables: la progression locale y est associée.
